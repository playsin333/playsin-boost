Process Explorer
Кто использует CPU, память и диск

Официальная страница: https://learn.microsoft.com/en-us/sysinternals/downloads/process-explorer

КОМУ ПРИГОДИТСЯ
Когда нужно найти конкретную фоновую нагрузку.

ШАГИ
1. Запусти официальный Process Explorer. Посмотри дерево процессов и отсортируй по CPU.
2. Через View → Select Columns добавь нужные показатели: Private Bytes, Working Set, I/O. Не путай выделенную частную память с физической RAM.
3. Открой Properties подозрительного процесса: проверь путь, команду, цифровую подпись и график нагрузки.
4. Наблюдай проблему в момент её появления. Не завершай системные процессы и не меняй приоритеты всех программ одновременно.

КАК ПОНЯТЬ РЕЗУЛЬТАТ
Краткий всплеск не равен постоянной нагрузке. Большой Working Set не всегда означает утечку. При необходимости сопоставь наблюдение с Диспетчером задач.

ВОЗВРАТ И ОГРАНИЧЕНИЯ
Просмотр не меняет настройки. Если вручную завершить процесс, несохранённые данные могут потеряться. Этот гайд не предлагает завершение процессов.
