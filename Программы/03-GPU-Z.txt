КОМУ ПРИГОДИТСЯ
Когда нужно проверить модель видеокарты, VRAM и ограничения под нагрузкой.

ШАГИ
1. На Graphics Card проверь GPU, Memory Size и версию драйвера. На системах с несколькими GPU выбери нужный снизу.
2. Открой Sensors: GPU Load, Memory Used, GPU Clock, температура. При необходимости включи Log to file.
3. Запусти привычную игру, затем изучи датчики. На поддерживаемых NVIDIA посмотри PerfCap Reason; набор датчиков AMD отличается.
4. Учитывай лимит FPS и V-Sync: при них неполная загрузка GPU может быть нормальной. Не обновляй BIOS видеокарты ради диагностики.

КАК ПОНЯТЬ РЕЗУЛЬТАТ
Большая занятость VRAM не всегда означает нехватку памяти: сравни характер статтеров и поведение игры при уменьшении текстур. Максимум загрузки GPU указывает на возможный графический предел, но не является полным диагнозом.

ВОЗВРАТ И ОГРАНИЧЕНИЯ
Наблюдение не требует изменений драйвера. Закрой программу. Не используй функции работы с BIOS, если не решаешь отдельную согласованную задачу.
