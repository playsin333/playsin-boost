Autoruns
Подробная автозагрузка Windows

Официальная страница: https://learn.microsoft.com/en-us/sysinternals/downloads/autoruns

КОМУ ПРИГОДИТСЯ
Когда списка автозагрузки в BOOST недостаточно.

ШАГИ
1. Распакуй официальный архив Microsoft Sysinternals и запусти Autoruns64. Для просмотра системных записей может понадобиться администратор.
2. Сохрани исходный снимок через File → Save. В Options включи проверку подписей; учти, что скрытие Microsoft не означает безопасность остальных записей.
3. Начни со вкладки Logon. Посмотри Publisher, Image Path и назначение программы. Неподписанная запись не обязательно вредоносная.
4. Отключай одну понятную запись снятием флажка, затем перезайди и проверь нужную функцию. Не удаляй записи и не отключай Drivers/Services массово. Не отправляй файлы в онлайн-сервисы без необходимости.

КАК ПОНЯТЬ РЕЗУЛЬТАТ
Снимок помогает сравнить состояние, но сам файл .arn не является полным автоматическим восстановлением Windows. Сохрани список конкретно снятых отметок.

ВОЗВРАТ И ОГРАНИЧЕНИЯ
Для возврата поставь флажок той же записи. Защитные, дисковые, сетевые, звуковые и OEM-компоненты не отключай, если не понимаешь их роль.

Это отдельная необязательная утилита. BOOST не запускает её по этому гайду и не требует её установки. Состав меню и лицензия зависят от версии; перед скачиванием проверь текущую страницу разработчика.
