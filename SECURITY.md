# Сообщения об уязвимостях

Для приватного сообщения свяжись с автором через личные сообщения в [Discord-сообществе](https://discord.gg/brMD3VYUAu). Если личные сообщения недоступны, попроси приватный способ связи, не публикуя детали эксплуатации.

Укажи версию, сборку Windows, затронутый файл, условия воспроизведения и последствия. Не отправляй пароли, токены и полные пользовательские резервные копии. Срок ответа заранее не гарантируется.

Обычные баги: [Issues](https://github.com/playsin333/playsin-boost/issues/new/choose). Старые ZIP 3.0.9–3.0.11 сохранены для истории и не исправляются под прежними номерами. [Ограничения](docs/SAFETY.md).
