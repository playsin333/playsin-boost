# Что проверено

## Автоматические проверки

[GitHub Actions](https://github.com/playsin333/playsin-boost/actions/workflows/validate.yml) проверяет:

- CRC ZIP, SHA256 архива и каждого файла, версию и состав комплекта.
- Совпадение распакованных данных с исходниками и воспроизводимость сборки в одном окружении.
- Хеши опубликованных медиаматериалов и ссылки в документации.
- Выбор источника обновлений: новый канал, миграцию точного старого официального адреса, приоритет пользовательского источника, отсутствие записи в его файл и отказ для небезопасных URL.
- Изолированный тест источника выполняется на Windows в PowerShell 7 и Windows PowerShell 5.1. Сервер Linux проверяет только упаковку; программа предназначена для Windows.

Зелёный статус относится к этим проверкам. Он не означает замер производительности или полную проверку всех твиков на физическом ПК.

## Что ещё требует проверки

Реальный запуск BAT, UAC, конкретные драйверы, применение и возврат настроек, перезагрузка и работа игровых переключателей требуют отдельной проверки на Windows. Выполнять такие изменения автоматически на рабочем ПК для проверки репозитория не следует.

Локальный полный тестовый стенд при переносе был остановлен защитой Windows с сообщением о блокировке содержимого скрипта. Защита не отключалась, успешное прохождение полного стенда не заявлено. Точное имя обнаружения нужно получить отдельно; предположение о ложном срабатывании не является подтверждением.

Исторические тесты прежних версий: [VALIDATION-RESULTS.md](VALIDATION-RESULTS.md). Матрица реальных проверок: [WINDOWS-VALIDATION.md](WINDOWS-VALIDATION.md). [Безопасность и откат](SAFETY.md).
