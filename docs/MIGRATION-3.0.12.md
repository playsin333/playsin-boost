# Перенос 3.0.12

Основа: предыдущая сборка 3.0.11. Перед изменениями сверены все 52 исходных файла с Git-объектами. Старая приватная история и резервные данные пользователей не публикуются.

Изменения:
- Публичный канал и ссылки на playsin333/playsin-boost.
- Переход с точного старого официального ManifestUrl без перезаписи пользовательских файлов. Произвольные пользовательские источники сохраняются.
- Новый Discord, главная, инструкции, FAQ, описание отката и поддержки.
- Полный текст лицензии NVIDIA Profile Inspector; runtime-файлы NVIDIA и checker сохранены.
- Медиа отдельно от пользовательского пакета. Исторические ZIP 3.0.9–3.0.11 не изменялись.
- Версия 3.0.12, пересобранные суммы и воспроизводимый ZIP.

Автоматические проверки выполняются без применения настройки Windows. Их итог публикуется вместе с результатом сборки. Они не доказывают совместимость драйверов, реальное применение настроек или прирост производительности на каждом ПК.

Проверено: синтаксис PowerShell; CRC, SHA256 и состав ZIP; соответствие файлов пакета Git-объектам; анонимное скачивание публичного ZIP. Выполнение полного тестового стенда остановлено защитой Windows с сообщением о блокировке содержимого скрипта; успешное прохождение не заявляется. Защита не отключалась.

Дополнительно пройдены 9 изолированных проверок выбора источника обновлений в PowerShell 7. Полный стенд заблокирован защитой Windows; запуск PS1 в Windows PowerShell 5.1 также ограничен текущей Execution Policy. Проверка ZIP, воспроизводимости, 11 медиафайлов и 26 относительных ссылок пройдена.
