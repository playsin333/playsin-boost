# Начало работы

1. [Скачай ZIP 3.0.13](https://github.com/playsin333/playsin-boost/raw/refs/heads/main/releases/v3.0.13/PLAYSIN-BOOST-3.0.13.zip), распакуй целиком в обычную папку.
2. Оставь папки `nvidia`, `checker`, `Программы` и файлы метаданных рядом с `PLAYSIN BOOST 3.0.bat`.
3. Запусти BAT. Нужна Windows 10/11 x64; используется штатный Windows PowerShell 5.1.
4. Начни с **3 — Проверить ПК**. Эта проверка не применяет настройки.
5. Выбери набор в пункте 1 или ручной выбор в пункте 2. Прочитай план; от него можно отказаться.
6. Подтверди понятные тебе действия и повышение прав своей учётной записи Windows. После применения прочитай итог и выполни требуемую перезагрузку.

## Основные пункты меню

| Пункт | Действие |
| --- | --- |
| 4 | История и откат |
| 5 | Игровой режим |
| 6 | Самопроверка BOOST |
| 9 | Обновить служебные скрипты из текущей версии |
| 10 | Параметры игрового режима |

| 13 | Обновить сам комплект |
| 14 | Отдельный TWEAK CHECK |

## Переход со старой версии

Сначала распакуй 3.0.13 рядом со старой версией. Не удаляй `C:\PLAYSIN333` на системном диске. Запусти новый BAT и выбери 9, если служебные скрипты уже установлены. Повторно применять настройку ради обновления кода не нужно. Обновление не отменяет прежние параметры Windows.

В новом BAT точный прежний официальный адрес канала направляется в публичный playsin-boost; произвольные пользовательские источники не заменяются. Старый BAT не получает эту логику сам — первый переход нужен вручную.

## Ошибка запуска

Подробности находятся в `%TEMP%\PLAYSIN-BOOST-error.txt`. Укажи версию, сборку Windows, действия и нужный фрагмент лога без личных данных в [Issues](https://github.com/playsin333/playsin-boost/issues/new/choose) или [Discord](https://discord.gg/brMD3VYUAu).
