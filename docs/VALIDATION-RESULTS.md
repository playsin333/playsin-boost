# Результаты проверок

## 3.0.11 — номер версии в главном меню

Общий набор: 164 проверки; обновлятор: 39. В проверке запуска свежий процесс загружает исходный BAT из пути со спецсимволами, вызывает главное меню и сверяет видимый номер с версией программы. Результат — 3.0.11, вместо оставшейся в прежнем меню строки 3.0.7. Настройки Windows не применялись; системные команды имитировались.

Проверены одинаковые файлы в версионном ZIP и Git-архиве, контрольные суммы и соответствие канала обновления. Прежний ZIP 3.0.10 сохранён. Изменение затрагивает вывод версии, без изменения твиков.

## 3.0.10 — надёжность, FPS и временные настройки игры

Пройдены общий набор (164), Tuning (50), обновлятор (39) и одноразовый отчёт (21): всего 274 автоматические проверки. PowerShell 7.4.6, Linux. Системные команды Windows, Планировщик, драйверы, RTSS и сеть имитировались. Мост C# компилировался без вызова Windows API; журналы и установка во временные папки проверялись реальными файлами.

Покрыты явный выбор FPS и неверный ввод, частота монитора, отсутствие лимитера, NVIDIA-импорт только FPS с сохранением остальных отслеживаемых настроек, проверка пустой/повреждённой выгрузки, первый бэкап RTSS и последующие конфликты, ручная/автоматическая самопроверка. Также: фактическое состояние HAGS и ожидание перезагрузки, неизвестные возможности GPU, сохранение полей предпочтения GPU, отсутствие MSI без явного выбора/исходного DWORD, сохранение сжатия памяти и возврат самого первого состояния после повторных противоположных настроек.

Игровые сценарии: отдельная схема с минимумом CPU 5%, сохранение исходной и повседневной схем, отказ от устаревшей игровой схемы, восстановительная задача без игровой схемы, временная политика загрузок с журналом до записи, ошибка возврата и повторная попытка, последующее изменение пользователя, существующая/доменная политика, повреждённый журнал, один сброс после входа и сохранение выбора одноразового отчёта в пункте 10.

ZIP 3.0.10 и Git-архив проверены встроенным валидатором комплекта; их содержимое и суммы совпадают. Файловая установка сохраняет прежнюю папку и включает чекер. Это не проверка реальных лимитов FPS, влияния политики на загрузки, античитов, драйверов, AC/DC или Windows PowerShell 5.1 на Windows. Проверку готовой сборки на Windows выполняет владелец; прирост производительности не заявлен.

## 3.0.9 — автоматический сценарий пункта 13, канал ожидает публикации

Общий набор: 161 проверка. Отдельно пройдены 39 проверок обновлятора и 21 проверка одноразового отчёта, всего 221. PowerShell 7.4.6, Linux; системные команды, сеть, диалог выбора ZIP, ярлык и запуск нового BAT имитировались. Временные файлы и установка рядом проверялись реальными файловыми операциями.

Новые проверки обновлятора: источник внутри комплекта и приоритет прежней настройки, запрет HTTP/встроенного пароля/относительного URL, получение только метаданных до подтверждения, один запрос подтверждения перед ZIP, отмена без ZIP, актуальная версия без установки, сохранение старой папки и бэкапа, очистка загрузок, ошибка соединения, плохой хеш и установка локального ZIP без канала либо при недоступном интернете.

В сборке 3.0.9 канал перенесён в этот же `playsin333/pc-optimizer`: описание версии и версионный ZIP подготовлены для хранения в репозитории. Публичная видимость не включалась; новая площадка не создавалась. Проверены одинаковое содержимое Git-архива и комплекта, контрольные суммы, формат описания версии и установка ZIP во временную папку. Для первого подключения нужен один ручной переход на версию с каналом. Анонимное скачивание станет доступно после перевода репозитория в Public.

## 3.0.8 — интеграция TWEAK CHECK

2 ноября 2026. PowerShell 7.4.6, Linux. Повторно пройден общий набор из 161 проверки (`Run-Tests.ps1`, включая 12 новых проверок чекера), а также по 21 отдельной проверке автоотчёта и обновлятора: всего 203 проверки. ## Исходная проверка 3.0.4

2 ноября 2026. PowerShell 7.4.6, Linux. 149 автоматических проверок прошли. Системные операции Windows заменены имитацией; файловые операции над временными файлами выполнялись реально.

Проверено:

- Синтаксис основного BAT, встроенных тел и полностью сгенерированных отката, игрового режима и самопроверки.
- Точная команда загрузчика в отдельном процессе; путь с кириллицей, пробелами, апострофом и спецсимволами; сохранение ошибки ранней загрузки.
- Выбор блоков, пустой выбор, отмена, остановка после отказа восстановления и ошибки модуля, запись статуса.
- Атомарная запись JSON, предыдущая копия, повреждённый JSON, отказ записи до мутации реестра, общая блокировка.
- Возврат схемы игрового режима и сохранение последующего выбора пользователя.

- Сохранение самого первого значения BCD при повторной попытке.
- Откат DWord, QWord, Binary, MultiString, String, ExpandString и исходного отсутствия значения; конфликты с последующими изменениями.

Сверка с восстановленным `fbca35f`: сохранены все 178 исходных имён функций и 67 буквальных спецификаций реестра. Это контроль состава, не подтверждение пользы параметров. NVIDIA-ресурсы не менялись.

Не выполнены: реальный откат на Windows, Windows PowerShell 5.1 на самой Windows, физические NVIDIA/ноутбуки/Windows 10, оценка FPS и всех политик/драйверных параметров. Полная матрица: WINDOWS-VALIDATION.md. Обнаружение антивирусом на целевой Windows в этих тестах не проверяется.


Дополнительные сценарии 3.0.3: состав наборов и ограниченная RAM, защита автозагрузки и явный выбор неизвестной записи; сохранение уведомлений; Appx текущего пользователя без вызовов AllUsers/provisioning, явное удаление для всех, отказ без смены области, запись истории до удаления, совместимость старых/смешанных историй; область классических замен; отдельный выбор качества AMD; сохранение полей GPU-профиля EXE и отсутствие записи при пустом выборе; адаптивное питание без USB/гибернации; закрытие программы без принудительного завершения и с явным разрешением; сохранение игрового состояния при неудачном возврате схемы; настройка режима без закрытия приложений и отказ записи новых предпочтений до обновления старого скрипта.
